# nc_dlhgshows

A Nextcloud app for managing calendar entries with RSVP functionality.

## Features

- **Calendar View**: Displays events from a configured calendar in table format
- **RSVP System**: Users can confirm or decline attendance for events
- **Filtering**: Filter events by type (Performance, Request, Cancellation)
- **Statistics**: Administrators can display reports for specific user groups
- **Admin Settings**: Configurable calendar ID, display name, and groups for reports

## Installation

1. Copy the app to the `apps/` directory of your Nextcloud installation
2. Enable the app in Nextcloud administration

## Requirements

- Nextcloud 32+
- PHP 8.0+
